# Source Freshness Procedure

Treasury reports should rely only on source data that is within the freshness threshold defined by the team. When data is stale, the analyst should flag the issue and escalate for validation before the report is distributed.

- Freshness checks should compare the source timestamp to the current time.
- If data is older than the defined threshold, it is stale.
- Stale data should appear in the report warnings and be reviewed by a human.
