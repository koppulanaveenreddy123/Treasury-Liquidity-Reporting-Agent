# Simplified LCR Guidance

Liquidity coverage ratio is a quick indicator of the relationship between high-quality liquid assets and expected net cash outflows. In this educational MVP, the simplified ratio is calculated using amounts from positions, collateral, and a small set of expected cash flows.

- When outflows are zero, the ratio defaults to a neutral baseline.
- Any ratio that is unusually high or negative should be reviewed for data quality.
- Analysts must trace calculated values back to their source records.
